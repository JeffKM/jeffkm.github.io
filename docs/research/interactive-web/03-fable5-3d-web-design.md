# 03. Fable 5 + 3D 인터랙티브 웹 제작 코스

- **영상**: [Fable 5 for 3D Web Design is Next Level!!! (Interactive, Animated!)](https://www.youtube.com/watch?v=IR1tzLU-r_4)
- **채널**: Viktor Oddy (`@ViktorOddy`)
- **한 줄 요약**: 3D 소프트웨어 없이, 이미지 → 다면(multi-view) 이미지 → GLB 3D 모델 → 코딩 에이전트에 첨부 → 인터랙티브 웹으로 이어지는 파이프라인. 5개 프로젝트를 실습으로 관통한다.

> 제작자는 어떤 도구와도 제휴/스폰서 관계가 없다고 명시한다(자기 사이트 motionsites.ai 제외).

## 파이프라인 A — 이미지 한 장을 인터랙티브 3D로

```
레퍼런스 이미지 1장 (Pinterest 등)
   ↓ 이미지 편집 AI에 "정면·후면·좌·우 4면 뷰로 만들어줘"
4면 이미지 → 개별 파일로 분리
   ↓ multi-view 3D 생성 서비스에 업로드 → create model
3D 모델 → animate(휴머노이드면 auto-rig) → GLB export
   ↓ Claude에 드래그 앤 드롭
"배경 이미지를 이 모델로 교체하고, 모델이 커서를 따라오게 해줘"
```

- 4면 뷰를 한 번에 생성하도록 태스크를 설정하는 것이 정답이다(따로따로 요청하면 일관성이 깨진다).
- GLB는 매우 가볍다. 웹용이므로 텍스처는 1K~2K로 낮춰 내보낸다.
- **5분 이내**에 커서를 추적하는 3D 히어로 완성.
- 툴에 따라 GLB 업로드가 거부될 수 있어 붙여넣기 방식을 바꿔 재시도했다.

## 파이프라인 B — 참조 사이트를 내 사이트에 이식

1. Pinterest / Awwwards / Landbook 등에서 레퍼런스를 찾는다.
2. 먼저 **구조와 콘텐츠**만 있는 초안을 만든다("가상의 자동차 회사 사이트, 4~5개 섹션, 배경은 순수 검정").
3. 그다음 참조 프롬프트를 주면서 **"구현하지 말고, 디자인만 현재 사이트에 적용해"** 라고 지시한다.
   > 구조, 사이트 이름, 콘텐츠, 섹션, 텍스트, 푸터는 그대로 두고 **새 디자인만 적용**하라. 아래 보낼 프롬프트에서 그 외의 것은 가져오지 마라.
4. 결과: 폰트와 시각적 완성도만 교체되고 정보 구조는 유지된다.

콘텐츠와 스타일을 분리해서 지시하는 이 방식이 핵심 테크닉이다.

## AI 티가 나는 사이트의 4가지 신호

영상에서 명시적으로 지목한 항목이다.

1. 과도한 **자간(letter spacing)**
2. 습관적인 **그라디언트**
3. **밝은 배경** 일변도
4. 특정 **초록 계열 색상** + 카드에 얹은 그라디언트

회피 방법은 하나다 — **레퍼런스, 스크린샷, 명시적 스타일 지시를 준다.** 아무 지시 없이 "핀테크 사이트 만들어줘"라고 하면 정확히 위 네 가지가 나온다. MVP로는 나쁘지 않지만 실무용으로는 부족하다.

추가로 발견한 습관: **AI 모델은 불필요한 border/stroke를 즐겨 추가한다.** 좋은 디자인 관행이 아니므로 명시적으로 제거를 요청해야 한다.

## 인터랙션 기법 모음

- **CSS `mix-blend-mode: exclusion`** — 생성한 배경 영상을 페이지 배경과 자연스럽게 합성한다. 영상 원본 배경색이 달라도 블렌딩으로 녹아든다.
- **비디오 스크럽 성능** — 영상을 그대로 쓰는 대신 **MP4 → JPEG 시퀀스**로 변환하면 어떤 기기에서도 끊기지 않는다. (간단한 강의용으로는 영상을 그대로 사용)
- **텍스트 마스크 효과** — Figma에서 사각형과 텍스트를 Subtract → SVG로 내보내 AI에 전달하면 재현된다.
- **채도/불투명도/블렌드 조정** — 배경 영상이 읽기 어려우면 채도 0, 불투명도 70%, 블렌드 모드 변경으로 가독성을 되찾는다.
- **위계 우선** — 통계 패널이 메인 헤드라인을 방해하자 크기를 20% 줄였다. "웹 디자인에서 가장 중요한 것은 위계".

## Figma 활용 (영상의 5번째 프로젝트)

- **AI 애니메이션**: 애니메이션 아이콘 클릭 → "애니메이트" 요청 → 지속 시간 등 조정 가능. 패럴랙스도 요청할 수 있다.
- **영상으로 내보내기**: 서드파티 편집 도구 없이 Figma에서 바로 영상 export → SNS 공유나 클라이언트 전달.
- **커뮤니티**: 요소 선택 → "find similar designs" → community에서 완성된 디자인을 가져와 조합. 폰트/크기가 이미 설정되어 있어 스타일을 처음부터 만들 필요가 없다.
- **Shader Effects**: Tools → Shader Effects. Halftone, Warp, Pixel Stretch, Color Adjust 등. 이미지·텍스트·영상 모두에 적용 가능하고 애니메이션도 만들 수 있다.
- **배경 제거**, **Edit with prompt**(예: "밤으로 만들어줘"), **Dark Mode Magic 플러그인**으로 다크 테마 변환.
- 다크/라이트 토글은 Figma에서 프로토타입 연결로 시연 가능하다.
- 제작자 평: "Figma는 예전만큼 필수는 아니다. 한 달에 한 번 정도 쓴다. 기본 이해만 있으면 충분하다."

## 작업 순서에 대한 제작자의 원칙

> 에셋(이미지·영상)을 **먼저** 만들고, 그다음 UI를 만들고, 마지막에 결합한다.

프론트엔드를 백지에서 만들게 하지 않고, 마음에 드는 폰트/스타일 정의를 먼저 확보한 뒤 그것을 지시에 포함시킨다.

## 이 포트폴리오에 옮길 수 있는 것

- **"AI 티 4가지 신호"는 즉시 적용 가능한 체크리스트**다. 현재 사이트는 자간·색 사용이 의도적이므로 이 기준으로 한 번 감사(audit)할 가치가 있다.
- **불필요한 border 제거** — 이 사이트는 브루탈리즘 계열이라 테두리가 스타일의 일부다. 다만 "장식이 아니라 의도"인지 점검 대상.
- `mix-blend-mode`, 마스크, 셰이더류 효과는 **에셋 없이도** CSS만으로 상당 부분 구현 가능하다.
- 3D GLB + three.js 경로는 번들 의존성이 추가되므로, 이 저장소의 "의존성 최소 · 완전 정적" 원칙과 충돌 여부를 먼저 판단해야 한다.
